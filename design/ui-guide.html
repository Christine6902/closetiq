Foundation

Icon system

Library: Lucide (lucide.dev), 1.5px stroke. In production: CDN script + <i data-lucide="name"> then lucide.createIcons(). Here, icons are inline <svg> using currentColor.

Line length — 65ch keeps copy readable

A good outfit recommendation is short and specific. ClosetIQ constrains body copy to about sixty-five characters so suggestions read like a note from a stylist, not a wall of text.
